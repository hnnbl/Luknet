Create `src/app/components/BackgroundEffects.tsx` as a fixed-position, full-viewport background layer. It renders below all content (z-index 0 or negative, with pointer-events: none so it never blocks clicks).

**Structure of the component:**

```tsx
import { motion } from 'motion/react';

export function BackgroundEffects() {
  return (
    <div className="fixed inset-0 pointer-events-none overflow-hidden" style={{ zIndex: 0 }}>
      {/* Animated gradient layer */}
      {/* Radial orb overlays */}
      {/* Floating particle dots */}
    </div>
  );
}
```

**Layer 1 — Pulsing gradient background:**
A div with an animated multi-stop gradient that shifts position to create a pulsing/breathing effect. Use the `.animate-gradient-pulse` class defined in theme.css (which animates background-position). The gradient should go from deep black through dark purple to violet and back:

```tsx
<div
  className="absolute inset-0 animate-gradient-pulse"
  style={{
    background: 'linear-gradient(135deg, #000000 0%, #0a0014 20%, #1a0a3a 40%, #0d0020 60%, #000000 80%, #0a0014 100%)',
    backgroundSize: '400% 400%',
  }}
/>
```

**Layer 2 — Purple radial orbs (gives depth and warmth to the gradient):**
Three semi-transparent radial gradient orbs at different positions, different sizes. Use `motion.div` with a `animate` prop cycling opacity to create a slow pulse. Do NOT use `animate-pulse` Tailwind class here (it's too mechanical) — use motion's `animate` with `transition: { duration: 6, repeat: Infinity, repeatType: 'mirror' }`.

Orb 1 (top-left region): `radial-gradient(circle, rgba(124,58,237,0.15) 0%, transparent 70%)`, size 600px x 600px
Orb 2 (center-right region): `radial-gradient(circle, rgba(167,139,250,0.1) 0%, transparent 70%)`, size 800px x 800px
Orb 3 (bottom-left region): `radial-gradient(circle, rgba(109,40,217,0.12) 0%, transparent 70%)`, size 500px x 500px

Each orb: `position: absolute`, different `top`/`left`/`right` percentage values to distribute across the viewport. Wrap each in `motion.div` with:
```tsx
animate={{ opacity: [0.4, 0.8, 0.4] }}
transition={{ duration: 6 + i * 2, repeat: Infinity, ease: 'easeInOut' }}
```

**Layer 3 — Floating particle dots:**
20 small circular dots of varying sizes (2px–4px diameter), scattered at pseudo-random fixed positions across the viewport. Use a hardcoded array of positions (percentage-based top/left) so there is no random seed issue on re-render. Use `motion.div` with `.animate-particle-drift` style but apply via motion `animate` instead for variety in timing.
