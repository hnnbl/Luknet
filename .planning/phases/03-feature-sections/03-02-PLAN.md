**Part A — Scroll-triggered entrance animations using motion/react whileInView:**

Define motion variants outside the component function (before `export function DifferentialsSection()`):

```tsx
const sectionVariants = {
  hidden: {},
  visible: {
    transition: { staggerChildren: 0.15 },
  },
};

const itemVariants = {
  hidden: { opacity: 0, x: -30 },
  visible: {
    opacity: 1,
    x: 0,
    transition: { duration: 0.6, ease: 'easeOut' },
  },
};

const headerVariants = {
  hidden: { opacity: 0, y: -20 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.5, ease: 'easeOut' },
  },
};
```

Apply to the section structure:
1. Wrap the section header div (`text-center mb-16`) in a `<motion.div initial="hidden" whileInView="visible" viewport={{ once: true, amount: 0.3 }} variants={headerVariants}>` — the header slides down into view as one unit.
2. Wrap the differentials grid `<div className="grid md:grid-cols-2 gap-8">` with `<motion.div initial="hidden" whileInView="visible" viewport={{ once: true, amount: 0.1 }} variants={sectionVariants}>` — this is the stagger container.
3. Change each item's outer `<div>` to `<motion.div variants={itemVariants}>` — items slide in from the left with stagger.

This means: header enters first when scrolled to, then items stagger in with 150ms offsets as more of the grid comes into view.
