**Part A — 3D tilt on hover (mouse-reactive, pure React state + inline styles, no library):**

Add `useState` import from 'react'. For the cards grid, wrap each card in a perspective container and wire a mouse position handler:

Pattern (for each card in the `.map()`):

```tsx
const [tilt, setTilt] = useState<{ x: number; y: number }>({ x: 0, y: 0 });
```

Since useState inside map is not valid (hooks must be at top level), define the tilt state for all 4 cards at the top of the component using an array:

```tsx
const [tilts, setTilts] = useState<{ x: number; y: number }[]>(
  services.map(() => ({ x: 0, y: 0 }))
);
```

In the map callback, add to each card container div:
- `onMouseMove` handler: `(e) => { const rect = e.currentTarget.getBoundingClientRect(); const x = ((e.clientY - rect.top) / rect.height - 0.5) * 15; const y = -((e.clientX - rect.left) / rect.width - 0.5) * 15; setTilts(prev => prev.map((t, i) => i === index ? { x, y } : t)); }`
- `onMouseLeave` handler: `() => setTilts(prev => prev.map((t, i) => i === index ? { x: 0, y: 0 } : t))`
- Wrap the card div in an outer `<div style={{ perspective: '800px' }}>` container with no other classes.
- Apply the tilt via inline style on the card div itself: `style={{ transform: \`rotateX(\${tilts[index].x}deg) rotateY(\${tilts[index].y}deg)\`, transition: 'transform 0.15s ease-out' }}`

This creates a smooth mouse-following 3D tilt capped at ±7.5 degrees on each axis.
