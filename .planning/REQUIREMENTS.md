# Requirements: Luknet — Landing Page Futurista

**Defined:** 2026-03-14
**Core Value:** Causar impacto visual imediato — o visitante sente que a Luknet é tech de ponta antes de ler uma palavra.

## v1 Requirements

### Theme

- [ ] **THEME-01**: Página usa tema dark como padrão global (fundo #000 ou próximo)
- [ ] **THEME-02**: Paleta primária em roxo/violeta com acentos neon
- [ ] **THEME-03**: Gradiente animado roxo/violeta pulsa no background da página
- [ ] **THEME-04**: Partículas flutuantes no background em toda a página

### Hero

- [ ] **HERO-01**: Hero section exibe elemento 3D central flutuando com animação contínua
- [ ] **HERO-02**: Headline do Hero é bold, grande e de alto impacto visual
- [ ] **HERO-03**: Copy do Hero transmite posicionamento tech premium da Luknet
- [ ] **HERO-04**: Animação de entrada do Hero é impactante (não sutil)

### Services

- [ ] **SERV-01**: Cards de serviços têm efeito visual 3D/holográfico
- [ ] **SERV-02**: Cards de serviços inclinam (3D tilt) ao passar o mouse (hover)
- [ ] **SERV-03**: Textos dos serviços são atualizados com copy premium

### Differentials

- [ ] **DIFF-01**: Seção de diferenciais redesenhada com visual futurista dark
- [ ] **DIFF-02**: Elementos da seção têm animação de entrada no scroll
- [ ] **DIFF-03**: Copy dos diferenciais atualizado

### Header

- [ ] **HEAD-01**: Header redesenhado com estilo dark e coerente com o novo tema
- [ ] **HEAD-02**: Header mantém responsividade mobile

### Remaining Sections

- [ ] **SECT-01**: Seção de Notícias/Blog redesenhada com estilo dark
- [ ] **SECT-02**: Seção de Contato redesenhada com estilo dark e futurista
- [ ] **SECT-03**: Footer redesenhado com estilo dark e coerente
- [ ] **SECT-04**: Animações de entrada no scroll em todas as seções

### Typography & Copy

- [ ] **COPY-01**: Tipografia bold e headlines de impacto em toda a página
- [ ] **COPY-02**: Textos de todas as seções revisados e atualizados

## v2 Requirements

### Avançado

- **ADV-01**: Cursor customizado com efeito neon
- **ADV-02**: Header glassmorphism com blur
- **ADV-03**: Efeito scroll parallax entre seções
- **ADV-04**: Modo claro alternativo
- **ADV-05**: Transições de página animadas

## Out of Scope

| Feature | Reason |
|---------|--------|
| Backend / API | Foco exclusivo em frontend/visual |
| Autenticação | Landing page sem login |
| Mobile app | Web only |
| Internacionalização | Apenas pt-BR |
| CMS | Conteúdo estático por ora |
