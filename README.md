# JN Tecnologia — Soluções Inteligentes

Landing page futurista da **JN Tecnologia**, desenvolvida por **Jordão Nunes**.

Automação com IA, Python e n8n para negócios que não querem depender de trabalho manual.

---

## Stack

- **React 18** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Framer Motion** (`motion/react`) — animações e efeitos 3D
- **Lucide React** — ícones

## Funcionalidades

- Tema dark global com paleta violet/purple neon
- Background animado com partículas flutuantes e orbs
- Hero section com elemento 3D flutuante e animação de entrada dramática
- Cards de serviços com efeito holográfico e 3D tilt no hover
- Seções com animações de entrada no scroll (`whileInView`)
- Header glassmorphism com blur responsivo
- Formulário de contato funcional
- Footer com links para GitHub, Instagram e site

## Como rodar

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
```
